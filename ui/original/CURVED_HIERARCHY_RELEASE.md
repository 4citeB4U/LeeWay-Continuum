# LeeWay Continuum Curved Hierarchy / Local Media UI

The live Continuum interface remains under Runtime Fabric's existing
\`machine-consciousness/continuum/ui/\` assets and same-origin owner-scoped provider.

## Canonical behavior
- Start sphere-only; the owner can collapse/expand left navigation.
- Clicking a category extends its source-derived honeycombs outward with a curved,
  translucent camera-facing arrangement while automatic sphere rotation pauses.
- Nested collection, recorded Brain parent and actual recorded file-path directory
  relationships are navigable; the owner can back out one level at a time.
- A selected file opens inside the large parent honeycomb; surrounding cells dim.
  Inline viewers: verified image, video, audio, PDF and DOCX, plus bounded UTF-8.
  Blob data is **created only after the existing SHA-256 and byte-length check**.
- The 92 original geodesic sphere cells remain intact. Additional *visual* occupancy
  cells are derived deterministically from actual connected source counts; these do
  not create database rows, file objects or independent new cognition.
- Source indexes remain explicitly marked index-only, without implying original bytes.
- The owner-local phone may have a smaller and different inventory; PC and Android
  must never synthesize another body's records.

## Security and provenance
- Immutable source identities and existing owner/provider APIs retained.
- No new database, origin, authority, autonomous ingestion or Formula approval.
- Local HTML viewer scripts are hash-admitted on Android with existing SOURCE.json.
- DOMPurify v3.4.16 (Apache 2.0 / MPL 2.0), Mammoth v1.13.0 (BSD-2-Clause);
  bundled JS in this directory keeps upstream license headers and no external CDN.
- Scripts execute locally only; no provider-supplied HTML is trusted as a page.
- Original Word rendering is sanitized; unsupported formats show an explicit status.
- On PC, PDF viewing uses the local browser PDF reader. Android WebView PDF rendering
  must be separately qualified on physical hardware before claiming that function.

## Evidence
- Owner-local Windows: 13/13 integration acceptance, 17/17 media/browser tests
  with synthetic *test-only* fixture bytes and tampering rejection,
  8/8 hierarchy tests, 8/8 412px phone-sized layout tests.
- Tests do not install sample data or change the existing owner Continuum DB.
- Physical Fold6 package signing, update, and native WebView behavior have their
  own distinct acceptance gates.
